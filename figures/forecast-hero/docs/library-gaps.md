# Library gaps
- Tree-ensemble glyph (`figure/parts.js`, `trees`): no library part draws a boosted-tree ensemble; built from lines, circles and squares, with an optional staggered second row.
- Superscript hat and star (`figure/hero.js`, `hat`, `star`): the maths font places U+0302 badly over α and its asterisk / ⋆ are too small at web size, so both marks are drawn as vector paths at the glyph's position.
